# Japan Tourism & Economic Insights Data Analysis Project

## 📌 Project Overview
This project analyzes the post-pandemic recovery and market growth of tourism in Japan, focusing on visitor inflow and economic spend patterns. It demonstrates end-to-end data capabilities including **Data Processing using Python**, **Advanced Analytics via SQL**, and trend reporting.

---

## 🛠️ Tech Stack & Skills Demonstrated
- **Data Manipulation:** Python (Pandas, NumPy)
- **Database & Querying:** SQL (Window Functions, Aggregations, Joins)
- **Data Visualization:** Matplotlib (Data Trend Plotting)
- **Analytical Concepts:** Year-over-Year (YoY) Growth Calculation, Market Segmentation

---

## 📊 Key Insights Found
1. **Exponential Inflow Growth:** Tourist inflow from the target region witnessed a sharp post-pandemic recovery, growing by over 100% Year-over-Year (YoY) between 2022 and 2024.
2. **Shift in Consumer Behavior:** The primary purpose of travel successfully shifted from business-centric trips to high-spending leisure travel, increasing the average spend per tourist.
